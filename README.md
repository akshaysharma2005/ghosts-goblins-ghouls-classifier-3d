## 🌟 Overview

The **Supernatural Creature 4D Classifier & Biometric Space** delivers advanced geometric visualization and ensemble machine learning for paranormal biological specimens. Classifying between *Ghouls, Goblins, and Ghosts* using normalized physical attributes (bone length, rotting flesh, hair length, soul power, and spectral aura), this system maps creature boundaries in continuous 3D space and features a real-time Soft Voting Ensemble Classifier (Random Forest + Extra Trees + Gradient Boosting).

## ✨ Features & Visual Dimensions

### 📊 1. 2D Biometric Profiling
- **Species Violin & Box Distributions**: High-density distributions for bone length, rotting flesh, hair length, and soul metrics.
- **Spectral Color Frequency Groupings**: Multi-colored bar comparisons highlighting aura pigmentation preferences (*clear, green, black, white, blue, blood*).

### 🌐 2. 3D Biometric Morphospace & Species Envelopes
- **3D Spatial Mapping**:
  - **X-Axis**: Bone Length Index
  - **Y-Axis**: Rotting Flesh Index
  - **Z-Axis**: Hair Length Index
  - **Marker Size**: Soul Luminosity
  - **Color**: Species (*Ghoul in Emerald, Goblin in Amber, Ghost in Cyan*)
- **3D Convex Hull Enclosures**: Automated Delaunay triangulation meshing defining the physical boundary of each monster species.

### ⏳ 3. 4D Soul Resonance Evolution
- **4D Hyper-Dimensional Projection**:
  - **Dim 1 (X)**: Bone Length
  - **Dim 2 (Y)**: Rotting Flesh
  - **Dim 3 (Z)**: Hair Length
  - **Dim 4 (Color)**: Species
  - **Dim 5 (Size)**: Soul Power
  - **Dim 6 (Time / Frame Animation)**: Soul Resonance Tiers (*Faint Aura → Dim Essence → Radiant Soul → Luminous Spirit → Transcendent*)
- Watch Ghosts and Ghouls cleanly dissociate as ethereal soul presence intensifies.

### 🔮 4. Real-Time Cryptid Voting Classifier
- Input physical measurements into our tripartite Soft-Voting Ensemble (*Random Forest + Extra Trees + Gradient Boosting*) for immediate taxonomic identification and confidence intervals.

## 🚀 Getting Started

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/akshaysharma2005/ghosts-goblins-ghouls-classifier-3d.git
   cd ghosts-goblins-ghouls-classifier-3d
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch the Dashboard**:
   ```bash
   streamlit run app.py
   ```

4. Navigate to `http://localhost:8501`.
